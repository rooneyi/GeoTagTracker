# GeoTagTracker Admin

Interface d’administration web pour la gestion des soumissions et techniciens.

## Installation

```sh
npm install
```

## Lancement en développement

```sh
npm run dev
```

## Configuration

Copiez `.env` ou adaptez les variables selon votre environnement.

## Fonctionnalités principales
- Authentification JWT
- Dashboard
- Gestion des soumissions (listes, détails, carte)
- Gestion des techniciens
- UI conforme à la charte graphique Orange

## API
L’URL de l’API est définie dans `.env` via `VITE_API_URL`.

## Build

```sh
npm run build
```
